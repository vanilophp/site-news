Vanilo 5.2 has been released with Laravel 13 support.

Originally we planned to add Laravel 13 support to Vanilo 6, but we decided to release it as a minor update to Vanilo 5.2.
Another change in this release is that the minimum Laravel 12 version is now 12.50.

No other features or fixes have been added to this release.

## Supported Versions

- PHP 8.3, 8.4 and 8.5 are supported
- Laravel 10 is still supported, v10.48 remains the minimum requirement
- Laravel 11.46.2 is the minimum requirement for the v11 series, and
- Laravel 12.50 is the minimum requirement for the v12 line.
- Laravel 13.0+ for the latest Laravel version.
